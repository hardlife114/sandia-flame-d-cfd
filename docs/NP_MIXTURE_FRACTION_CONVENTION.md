# 非预混混合分数口径：两套定义的等价性与换算

> 更新：2026-09-14
> **读这份文档可以避免本项目最容易搞错的一件事：入口 f 到底填多少。**
> 相关：`docs/NP_PDF_TABLE_ISSUE.md`（为什么必须换口径）

---

## 1. 问题背景

Sandia Flame D 的**射流本身是"25% CH4 + 75% 空气"**，不是纯燃料。用非预混（equilibrium）
模型时，"燃料流"该定义成什么，有两种口径，**入口 f 的数值完全不同**，混用会直接算错。

---

## 2. 两套口径

### 口径 A（不推荐）：燃料流 = 射流混合物

```
燃料流（质量分数）: ch4 0.15637   o2 0.19650   n2 0.64713      ← 即射流组分
氧化剂流（质量分数）: o2 0.23574  n2 0.75800   h2o 0.006256    ← 即伴流湿空气
入口 f:  jet 1.0    pilot 0.27（TNF 文档值）    coflow 0.0
f_st = 0.3556
```

* **物理上最直观**，但实测会让 Fluent 生成**错误且偏冷的 PDF 表**
  （表内 T(f) 峰值落在 f≈0.10、最高仅 992 K；f=0.3556 处只有 ~610 K，应为 2225 K）。
* 详见 `NP_PDF_TABLE_ISSUE.md`。

### 口径 B（现行，推荐）：燃料流 = 纯 CH4，氧化剂 = 空气

```
燃料流（质量分数）: ch4 1.0
氧化剂流（质量分数）: o2 0.232   n2 0.768        （带水的版本见 §5）
入口 f:  jet 0.15607    pilot 0.04214    coflow 0.0
f_st = 0.0552
```

* 实测 PDF 表正常（峰值在 f_st、温度 2000+ K）。

---

## 3. 等价性证明（关键，不是近似）

**口径 A 的混合线**（参数 f_A）：

```
composition_A(f_A) = f_A · 燃料流_A + (1 − f_A) · 空气
                   = f_A · (0.15607 CH4 + 0.84393 空气) + (1 − f_A) · 空气
                   = 0.15607·f_A · CH4 + (1 − 0.15607·f_A) · 空气
```

**口径 B 的混合线**（参数 f_B）：

```
composition_B(f_B) = f_B · CH4 + (1 − f_B) · 空气
```

**令 `f_B = 0.15607 · f_A`，两式逐项相同 → 两条混合线完全重合。**

因此：

* 混合分数是**守恒标量**，线性缩放在物理上合法；
* 非预混模型的 (T, Y_i) 完全由 (f, fvar) 决定 → **整个解只差一个常数缩放，物理场不变**；
* 缩放因子 **`f_B = 0.15607 · f_A`**（= 射流元素碳质量分数 / 纯 CH4 的元素碳质量分数
  = 0.117053 / 0.75）。

### 数值验证（射流点）

| | CH4 | O2 | N2 |
|---|---:|---:|---:|
| 口径 B 在 f=0.15607（= 0.15607 CH4 + 0.84393 空气） | 0.15607 | 0.19579 | 0.64814 |
| 实验射流（质量分数） | 0.15607 | 0.19650 | 0.64713 |

逐项吻合（差异来自空气取 O2 0.232/N2 0.768 而非精确值）。

---

## 4. 两种口径的换算表

| 量 | 口径 A | 口径 B |
|---|---:|---:|
| 射流入口 f | 1.0 | **0.15607** |
| pilot 入口 f | 0.27（文档值） | **0.04214**（= 0.27 × 0.15607） |
| 伴流入口 f | 0.0 | 0.0 |
| 化学计量 f_st | 0.3556 | **0.0552** |
| 换算关系 | — | **f_B = 0.15607 · f_A** |

**TNF 文档里给出的所有混合分数（含 pilot 的 0.27）都是口径 A**，用口径 B 时必须乘 0.15607。

---

## 5. 如果想保留伴流微量水分

氧化剂流可以填带水的空气：`o2 0.23574 / n2 0.758 / h2o 0.006256`
（即口径 A 的氧化剂）。

**因为水不含碳，`Z_C,ox = 0` 不变，所以 `f_jet = 0.15607` 不用改。**
带水与不带水的差别是 0.6% 质量分数，对温度与主要组分影响在小数点后第二位。

---

## 6. 与实验设定的符合性

| 项 | 实验 | 口径 B | 评价 |
|---|---|---|---|
| 射流组分 | 25% CH4 + 75% 空气 | f=0.15607 精确复现 | ✅ |
| 射流速度/温度 | 49.6 m/s, 294 K | 同 | ✅ |
| 伴流 | 空气（+0.6% 水） | f=0，干空气 | ⚠ 忽略 0.6% 水 |
| pilot | 燃烧产物, 1880 K | f=0.04214 | ✅ 线性折算；平衡表给出 ≈1850–1900 K，接近实验 |
| 化学计量 f | — | 0.0552，落在 0～0.156 之间 | ✅ |

### 两点模型固有近似（与口径选择无关）

1. **pilot 用 f 表示，而非其真实燃烧产物组分** —— 非预混平衡模型自身的假设，两套口径都一样。
2. **伴流微量水分** 在口径 B（干空气）下被忽略。

---

## 7. 落地位置

入口 f 已写入 `scripts/run_np_eq.py`：

```python
F_SCALE = 0.15607
INLETS = {
    "jet":    dict(..., F=1.0  * F_SCALE),   # 0.15607
    "pilot":  dict(..., F=0.27 * F_SCALE),   # 0.04214
    "coflow": dict(..., F=0.0),
}
```

**换口径时只改这一个常数，不要再动 Boundary 里的流组分。**
